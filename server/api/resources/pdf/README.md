# Printable report assets

These assets are bundled so PDF rendering never downloads images or fonts.

- `open-food-facts.svg`: the official logo for light backgrounds, downloaded from
  https://static.openfoodfacts.org/images/logos/off-logo-horizontal-light.svg.
- `green-score-*.svg`: copies of the project's official illustrations in
  `frontend/src/lib/assets/green-score`.
- `nutri-score-*.svg`: copies of the project's official Nutri-Score 2023 illustrations in
  `frontend/src/lib/assets/nutri-score`; see that directory's README for attribution.
- `LiberationSans-*.ttf`: Liberation Sans regular and bold. The accompanying
  `FONT-LICENSE.txt` contains the SIL Open Font License and copyright notices.

Keep the score illustrations synchronized with their frontend originals when updating them.
The fonts support Latin, Greek and Cyrillic text; other scripts may require additional fonts.
